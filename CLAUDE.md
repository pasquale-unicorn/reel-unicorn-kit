# Kit Reel Unicorn

Questa cartella è il kit di montaggio reel di Unicorn per Mary (videomaker).

- Se l'utente chiede di **installare** il kit ("installa il kit", "installa la cartella", "configura tutto"): segui `INSTALLA.md` passo per passo.
- Se l'utente chiede reel, momenti, bozze da una live: usa la skill `reel-unicorn` (in `skills/reel-unicorn/`).
- Lavora in italiano, una cosa alla volta, spiegando cosa fai in parole semplici: Mary è una videomaker esperta di Premiere, non una programmatrice.
- Non cancellare mai file di Mary. Le cartelle di lavoro dei reel stanno fuori dal kit, accanto ai video della live.
